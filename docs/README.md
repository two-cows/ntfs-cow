## Dependency updates

Renovate uses [the repository configuration](../.github/renovate.json) to open dependency update PRs. Enable the [Renovate GitHub App](https://github.com/apps/renovate) for this repository and merge the configuration into the default branch; the hosted service then runs automatically. See [installation and onboarding](https://docs.renovatebot.com/getting-started/installing-onboarding/).
